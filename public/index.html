Turn any Slack thread into memory a coding agent can recall.

Tag @recall-bot to capture threads. Use MCP to let your coding agent search and retrieve them anytime.

Add to Slack
Installing requires Slack workspace-admin permission or approval from whoever manages apps in your workspace. If that's not you, send this page to them — nothing is installed or configured until it clears Slack's own approval screen.

How it works

A workspace admin approves the requested scopes
Your workspace administrator reviews and approves the permissions recall-bot needs to read threads and send you setup instructions.
You get a one-time Slack DM with a dashboard setup link
After approval, recall-bot sends you a direct message containing a link to set up your personal dashboard and connect your coding agent.
Tag @recall-bot on any thread to capture it, or run /recall-key in a DM
Capture important threads by tagging the bot, then search and retrieve them through your coding agent's MCP connection for context-aware development.

Requested OAuth scopes (source: src/slack/receiver.ts)

  • app_mentions:read
  • channels:history
  • groups:history
  • im:history
  • mpim:history
  • chat:write
  • im:write
  • files:read
  • commands
